# DefencER MVP 밸런스 기준선

- 측정일: 2026-09-04
- 범위: 1~40라운드, 현재 유닛 4종, 카드 9종
- 실행: `BALANCE_SEEDS=64 npm run test:balance`

## 정책

- `initial-four-only`: 시작 유닛 4개만 사용한다.
- `auto-spend`: 빈 슬롯이 있는 동안 가능한 모든 크레딧을 복제에 사용한다.
- `auto-merge`: 복제 후 가능한 동일 유닛·성급을 즉시 합성하고 카드 우선순위를 적용한다.
- `auto-merge-first-card`: 자동 합성은 같지만 매 제시의 첫 카드를 골라 카드 편향을 비교한다.

하네스는 실제 플레이어의 배치·카드 판단을 완전히 재현하지 않는다. 승률의 절대값보다 수치 변경 전후와 정책 간 차이를 보는 회귀 기준선으로 사용한다.

## 조정 결과

| 일반 적 라운드당 체력 성장 | 정책 | 시드 | 승률 | 주 실패 |
| ---: | --- | ---: | ---: | --- |
| 2% | auto-merge | 64 | 84% | 36~38라운드 오버플로 |
| 3% | initial-four-only | 64 | 0% | 평균 12라운드 도달 |
| 3% | auto-spend | 64 | 0% | 30라운드 타임아웃, 후반 오버플로 |
| 3% | auto-merge | 64 | 67% | 35~39라운드 오버플로 |

3%에서 자동 합성 승리 런은 32시드 교차 측정 기준 평균 1,183초였다. 카드 제시의 첫 장을 고르는 자동 합성 정책은 66%, 승리 런 평균 1,195초였다. 실제 플레이에서는 준비와 카드 선택 시간이 더해지므로 목표인 약 20분 이상에 들어간다.

초기 역할 0~2명 보유군의 자동 합성 승률은 64시드에서 대체로 55~80%였다. 리오 0명도 72%로, 과거 10라운드 기준선의 리오 필수 편향은 재현되지 않았다. 표본이 적은 3~4명 보유군은 판단에서 제외한다.

## 현재 판단

- 2% 성장률은 자동 합성 정책 승률 84%로 너무 관대해 3%로 확정한다.
- 합성하지 않는 20유닛 정책은 30라운드 전후부터 막힌다. 후반 슬롯 압력과 합성 필요성이 의도대로 작동한다.
- 자동 합성 67%는 기본적인 성장 규칙을 이해한 기준 정책의 목표 구간 55~70%에 들어간다.
- 우선순위 카드와 첫 카드 정책의 승률이 각각 53%, 66%인 32시드 교차 결과상 특정 카드 선택이 완주를 독점하지 않는다.
- 개별 카드 보유군 승률은 58~77%였지만 인과 효과가 아닌 상관값이다. 실제 선택률·승률 수집 전까지 카드 수치의 추가 미세 조정은 보류한다.

## 다음 재측정 조건

신규 카드, 적 기믹, 유닛 또는 경제 수치를 바꾸면 같은 64시드 세트를 다시 실행한다. 자동 합성 승률 55~70%, 승리 런 20~35분, 초기 역할 0~2명 보유군 격차 30%p 이내를 임시 통과선으로 삼는다.
