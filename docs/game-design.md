# DefencER 게임 기획

DefencER는 이터널 리턴 IP를 활용한 PC 싱글플레이 로그라이크 디펜스다. 플레이어는 크레딧으로 실험체를 랜덤 복제하고 합성하며, 5라운드마다 아이템·규칙 카드 중 하나를 선택해 런의 방향을 만든다.

## 1. 제품 정의

- PC 1920×1080 기준
- 싱글플레이 브라우저 게임
- 백엔드 없는 클라이언트 단독 실행
- 영구 성장과 계정 전투 데이터 없음
- 정식 목표: 40라운드와 조건부 히든 라운드, 약 20~35분
- 프로토타입 목표: 10라운드 알파 처치
- 비공개 테스트 후 관련 커뮤니티 배포

정적 배포를 전제로 게임 상태와 규칙은 모두 브라우저에서 계산한다. 저장이 필요하면 로컬 저장소만 사용하며 서버, 로그인, 랭킹, 멀티플레이는 범위에 포함하지 않는다.

## 2. 핵심 플레이 루프

1. 전투 중 처치와 라운드 생존으로 크레딧을 얻는다.
2. 복제 비용을 확인하고 랜덤 실험체를 복제한다.
3. 실험체를 배치하거나 이동하고, 같은 실험체를 합성한다.
4. 아이템을 장착하고 규칙 효과와 시너지를 만든다.
5. 적 누적 상한을 넘기지 않고 라운드를 클리어한다.
6. 카드 지급 라운드를 클리어하면 아이템·규칙 카드 3장 중 하나를 선택한 뒤 다음 전투로 진입한다.

실험체 공급은 카드가 아니라 크레딧 경제로 담당한다. 카드는 전투 방향과 경제 운용을 결정하는 선택지다.

## 3. 전장

### 배치판과 트랙

- 배치판은 4행×5열, 총 20슬롯이다.
- 실험체가 배치된 슬롯에는 해당 실험체의 투명 배경 SD 유닛이 서 있는 모습으로 표시한다. SD 유닛은 슬롯 위에 직접 배치되어 전장에서 개별 실험체로 식별되어야 한다.
- 순환 트랙은 배치판 바깥을 ㅁ자 형태로 감싼다.
- 몬스터 순환 트랙과 맞닿은 배치판 슬롯을 외곽 슬롯, 맞닿지 않은 슬롯을 안쪽 슬롯으로 정의한다.
- 적은 한 방향으로 계속 순환하며 출구로 사라지지 않는다.
- 한 바퀴 자체에는 불이익이 없다.
- 중앙 슬롯은 외곽 슬롯보다 트랙에서 멀어 사거리 짧은 실험체에게 불리하다.

### 슬롯 조작

- 새 실험체는 왼쪽 위부터 행 우선으로 첫 빈 슬롯에 자동 배치한다.
- 빈 슬롯으로 드래그하면 이동한다.
- 같은 실험체·같은 성급 위로 드래그하면 합성한다.
- 합성할 때 드롭 대상 슬롯의 움직이지 않는 실험체를 기준 실험체로 하고, 그 위로 드래그한 실험체를 합성 재료로 한다.
- 합성 조건이 맞지 않으면 두 실험체가 슬롯을 교환한다.
- 전투 중에도 이동, 교환, 합성이 가능하다.
- 이동 중인 실험체는 0.75초 동안 공격하지 않는다.

### 피드백

- 빈 슬롯 이동 가능: 파란색
- 합성 가능: 금색과 반짝이는 아웃라인
- 슬롯 교환: 흰색
- 선택한 실험체: 기본 공격 사거리 표시
- 선택한 카드: 오른쪽 패널에서 효과와 적용 대상 표시

## 4. 런 진행과 패배

- 최초 실행 시 시작 크레딧 100을 지급한다.
- 첫 복제 딜러 보장은 두지 않는다.
- 시작 비용이 10이므로 플레이어는 첫 라운드 전에 여러 번 복제해 자신의 리스크를 선택한다.
- 일시정지는 없다. 단, 카드 선택 단계는 전투를 일시정지한다.
- 배속은 정식 범위지만 프로토타입에서는 제외한다.
- 일반 라운드는 30초다.
- 보스 라운드는 60초다.
- 필드 적이 정확히 50마리에 도달하면 즉시 패배한다.
- 일반 라운드는 시간만 지나면 성공한다. 살아남은 적은 다음 라운드로 넘어간다.
- 보스 라운드는 보스를 처치하면 즉시 성공한다. 이전 일반 적의 생존 여부는 성공 조건에 포함하지 않는다.
- 현재 필드 적과 출현 대기열이 모두 비었을 때만 라운드 스킵이 가능하다.

## 5. 라운드 구성

| 라운드 | 새로 출현하는 적 | 시간 |
| --- | --- | ---: |
| 1~9 | 고정 수의 일반·빠른 적 | 30초 |
| 10 | 알파 1마리 | 60초 |
| 11~19 | 강화된 일반·빠른 적 | 30초 |
| 20 | 오메가 1마리 | 60초 |
| 21~29 | 강화된 일반·빠른 적 | 30초 |
| 30 | 감마 1마리 | 60초 |
| 31~39 | 강화된 일반·빠른 적 | 30초 |
| 40 | 위클라인 1마리 | 60초 |
| 히든 라운드 | 진입 조건 충족 시 추가 전투, 세부 구성 추후 확정 | 미정 |

보스 라운드에는 일반 적을 새로 섞지 않는다. 이전 라운드의 생존 적은 필드에 남아 있을 수 있다.

40라운드 위클라인 처치 후에는 히든 라운드 진입 조건을 판정한다.

- 진입 조건을 충족하지 못하면 40라운드 클리어와 동시에 런을 클리어 처리한다.
- 진입 조건을 충족하면 40라운드 카드 선택을 진행한 뒤 히든 라운드에 진입한다.
- 40라운드는 카드 지급 라운드에 포함되지만, 히든 라운드에 진입하지 않는 런에서는 카드 선택을 표시하지 않는다.

### 일반 적 수

| 구간 | 첫 라운드 수 | 라운드별 증가 |
| --- | ---: | ---: |
| 1~9 | 5마리 | +1 |
| 11~19 | 15마리 | +2 |
| 21~29 | 34마리 | +3 |
| 31~39 | 62마리 | +4 |

프로토타입은 1~10라운드만 사용한다. 일반 적은 라운드 시작 후 0.3초 간격으로 순차 출현하며, 빠른 적은 5라운드부터 일반 적의 약 20%를 차지한다.

## 6. 크레딧 경제

### 복제 비용

복제 비용은 런 전체에서 증가한다.

`다음 복제 비용 = 10 + (성공한 누적 복제 횟수 × n)`

프로토타입 기준 `n = 10`이다.

| 누적 복제 | 현재 비용 | 누적 비용 |
| ---: | ---: | ---: |
| 1 | 10 | 10 |
| 2 | 20 | 30 |
| 3 | 30 | 60 |
| 4 | 40 | 100 |
| 5 | 50 | 150 |
| 6 | 60 | 210 |
| 10 | 100 | 550 |
| 15 | 150 | 1,200 |
| 20 | 200 | 2,100 |

복제 버튼은 현재 비용과 다음 비용을 함께 표시한다. 슬롯이 가득 찬 상태에서 실패한 복제 시도는 비용과 누적 복제 횟수를 바꾸지 않는다.

### 수입

| 수입원 | 프로토타입 기준 |
| --- | ---: |
| 기본 적 처치 | 10 |
| 빠른 적 처치 | 15 |
| 일반 라운드 생존 보상 | `50 + (라운드 번호 - 1) × 10` |
| 알파 처치 | 100 |
| 오메가 처치 | 150 |
| 감마 처치 | 200 |
| 위클라인 처치 | 300 |

일반 라운드 생존 보상은 시간 종료 시 지급한다. 적을 모두 처치하지 못해도 지급하며, 이 보상으로 처치가 느린 런도 다음 라운드에서 최소한의 회복 기회를 갖는다. 보스 보상은 보스 처치 즉시 지급한다.

### 무료 복제권

무료 복제권은 카드로만 얻는다.

- 무료 복제도 성공한 복제로 계산한다.
- 무료 복제 후 다음 복제 비용은 정상적으로 증가한다.
- 슬롯이 가득 차 복제하지 못하면 무료 복제권은 차감하지 않는다.

## 7. 폐기와 리롤

- 실험체는 전투 중 선택한 실험체 아래의 컨텍스트 오버레이에서 폐기할 수 있다.
- 장착 아이템이 없는 실험체만 폐기할 수 있다.
- 폐기 시 크레딧을 회수하지 않는다.
- 5성 실험체는 폐기할 수 없다.
- 아이템 자체는 플레이어가 수동으로 폐기·교체·제거할 수 없다. 단, 합성에서 기준 실험체가 아닌 쪽의 아이템은 해당 실험체와 함께 소멸한다.

리롤은 폐기와 무관하며 카드 선택 단계에서만 사용한다. 런 시작 시 3회를 지급하고, 10의 배수 라운드를 클리어할 때마다 1회를 추가 지급한다. 보유 상한은 없으며 한 카드 선택에서 여러 번 사용할 수 있다.

## 8. 합성과 성급

- 같은 실험체이면서 같은 성급인 두 개체를 합성하면 한 단계 높은 하나가 된다.
- 1성 두 개 → 2성, 2성 두 개 → 3성 방식이다.
- 5성이 최대다.
- 합성 결과는 기준 실험체의 아이템만 승계한다. 합성 재료의 아이템은 합성 결과로 이동하지 않는다.
- 성급 계수는 `100% / 120% / 140% / 160% / 180%`로 시작한다.
- 5성은 최종 성장 보너스로 유효 공격 또는 지원 수치에 추가 30%를 곱한다.
- 성급은 사거리, 스킬 범위, 대상 수, 스킬 쿨타임을 바꾸지 않는다.

5성은 기본 복제만으로 매 런 보장하는 목표가 아니다. 경제 카드와 좋은 수입 운, 중복 복제 운이 맞은 런에서 노릴 수 있는 최종 목표로 둔다.

## 9. 카드 시스템

카드의 UI는 이터널 리턴 **코발트 프로토콜의 장비·인퓨전 선택 화면**을 참고한다. 여기서 참고하는 것은 카드의 효과 규칙이 아니라 선택 패널의 시각적 형식이다.

### 카드 UI 디자인

- 카드 선택 단계에서는 코발트 프로토콜처럼 세로로 긴 선택 패널 3개를 가로로 나란히 배치한다.
- 각 선택 패널에는 상단 카드명, 중앙 아이콘, 카드 안쪽의 효과 설명을 배치한다.
- 카드 3개 아래 중앙에 원형 리롤 버튼 하나를 둔다. 리롤 버튼을 누르면 현재 제시된 카드 3개를 모두 다시 뽑는다.
- 리롤 버튼은 카드별 새로고침 버튼으로 분리하지 않는다.
- 선택 전에는 3개의 선택 패널을 동시에 보여주고, 선택한 항목만 청록색 외곽선과 밝은 배경으로 강조한다.
- 화면 맨 아래에는 카드 선택을 설명하는 별도 안내 문구를 표시하지 않는다.
- 카드 선택 UI는 전장 위에 오버레이로 표시하되, 배치된 SD 유닛과 전장 형태가 배경에서 식별 가능해야 한다.

### 선택 규칙

- 카드 지급 라운드는 `5·10·15·20·25·30·35·40`이며, 정규 구간에서 최대 8장의 카드를 선택한다.
- 카드 지급 라운드를 클리어한 뒤 카드 3장을 제시한다. 선택한 카드는 다음 라운드부터 적용한다.
- 카드 선택을 완료해야 다음 라운드를 시작할 수 있다.
- 40라운드 카드 선택은 히든 라운드 진입 조건을 충족한 경우에만 진행하며, 선택한 카드는 히든 라운드부터 적용한다.
- 같은 제시 안에서는 같은 카드가 중복되지 않는다.
- 아이템 카드는 선택한 뒤에도 다시 나올 수 있다. 선택한 규칙 카드는 같은 런에서 다시 나오지 않는다.
- 반대되는 효과의 규칙 카드도 같은 런에서 함께 선택할 수 있다. 예를 들어 `외곽 전술`과 `중앙 전술`은 서로를 자동으로 제외하지 않는다.
- 리롤로 다시 제시된 카드에는 직전 제시에서 보았던 카드가 다시 포함될 수 있다.
- 카드 풀에는 규칙 카드와 아이템 카드만 포함한다.
- 카드 3장의 규칙 카드·아이템 카드 구성 비율은 제한하지 않는다. 한 번의 제시에 한 종류만 3장 나올 수 있다.
- 카드 3장의 효과 방향도 제한하지 않는다. 세 장이 모두 순수 패널티 카드로 제시될 수 있다.
- 장착 가능한 실험체가 없는 아이템 카드는 제시하지 않는다.
- 5라운드 클리어 후 최초 카드 선택은 제한 시간 없이 진행한다. 이후 카드 선택은 20초다.
- 제한 시간 초과 시 제시된 카드 중 하나를 자동 선택한다.
- 카드 오버레이의 닫기 버튼을 누르면 오버레이만 숨겨진다. 카드 선택 단계는 유지되며 전장 정보만 확인할 수 있고 이동, 합성, 폐기, 복제는 할 수 없다.

아이템 카드는 선택과 동시에 대상 선택까지 완료해야 하며, 선택한 아이템 카드는 다음 라운드부터 적용된다. 대상 선택이 끝날 때까지 카드 선택 단계는 유지된다.
- 규칙 카드는 런 전체에 적용하며, 선택 당시의 실험체뿐 아니라 이후 복제되는 실험체에도 적용한다. 아이템 카드는 장착한 개별 실험체에만 적용한다.
- 모든 아이템은 모든 실험체에게 장착할 수 있다. 아이템별 추천 대상은 장착 제한이 아니라 효과가 특히 잘 맞는 추천 대상이다.
- 역할과 맞지 않아 효과가 없거나 매우 작아지는 아이템 장착도 허용한다.
- 실험체 하나에는 장착 아이템을 하나만 둘 수 있으며, 장착 후 다른 아이템으로 교체하거나 제거할 수 없다.

### 카드 목록

카드의 구체적인 이름, 효과 수치, 위험과 조건은 아직 설계하지 않았다. 현재 확정된 것은 규칙 카드와 아이템 카드의 적용 범위, 카드 선택 주기, 중첩 방식뿐이다.
프로토타입에서는 카드 희소성 등급을 사용하지 않는다. 정식 카드 풀이 확장된 뒤 필요하면 별도로 도입한다.

카드는 순수 이득형, 순수 패널티형, 이득과 리스크가 함께 있는 형식, 조건부 효과 등 어떤 구조든 허용한다. 카드의 효과 수와 위력에도 상한을 두지 않으며, 극단적으로 강한 카드도 만들 수 있다. 다만 일반적으로 리턴이 큰 카드일수록 더 큰 리스크·조건·희소성을 동반하도록 설계한다.

규칙 카드 효과와 아이템 카드 효과는 기본 수치에 곱연산한다. 규칙 카드는 이미 선택한 런에서는 다시 제시하지 않는다. 아이템 카드는 중복 선택할 수 있지만, 이미 장착 아이템이 있는 실험체에는 장착할 수 없다.

즉시 효과를 가진 카드는 카드 선택을 완료하는 순간 적용한다. 지속 효과를 가진 카드는 다음 라운드부터 적용한다.

## 10. 전투 공통 규칙

- 기본 공격은 투사체 방식이다.
- 일반 라운드에서는 사거리 안의 선두 적을 공격한다.
- 보스 라운드에서는 사거리 안의 보스를 우선한다.
- 투사체가 도착하기 전에 대상이 죽으면 투사체는 사라진다.
- 범위 피해는 중심 범위 안의 모든 적에게 동일 피해를 준다.
- 모든 고유 스킬은 초 단위 쿨타임이 끝나면 자동 발동한다.
- 플레이어는 스킬을 직접 발동하지 않는다.
- 스킬 발동 시 SD 유닛 연출과 별도 이펙트를 함께 보여준다.

## 11. 역할과 프로토타입 실험체

| 실험체 | 역할 | 기본 공격 | 고유 스킬 |
| --- | --- | --- | --- |
| 현우 | 근접 | 짧은 사거리, 높은 피해, 중간 공격 속도 | 4초마다 선두 적 강타 |
| 리오 | 원거리 | 긴 사거리, 빠른 공격 속도, 중간 피해 | 4초마다 선두 적 집중 사격 |
| 아디나 | 스킬 | 긴 사거리, 약한 기본 공격 | 6초마다 선두 중심 범위 피해 |
| 레니 | 서포터 | 중간 사거리, 낮은 피해 | 8초마다 비서포터 하나에 곰돌이 표식 |

레니의 표식 대상이 적중 공격을 하면 곰돌이가 날아가 추가 피해를 주고 레니의 다음 스킬 쿨타임을 줄인다. 서포터는 공격형 고유 스킬을 사용하지 않는다.

### 지원 효과

- 레니는 사거리 안의 비서포터 실험체 중 하나를 무작위 선택한다.
- 서포터 자신과 다른 서포터는 대상에서 제외한다.
- 지원 효과는 곱연산으로 중첩한다.
- 최종 지원 효율은 80%를 상한으로 한다.
- 지원 발동, 대상, 지속시간은 시각적으로 표시한다.
