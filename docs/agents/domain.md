# Domain Docs

이 저장소는 단일 컨텍스트 구조를 사용한다.

## 작업 전에 읽을 문서

- 루트의 `CONTEXT.md`: 프로젝트 고유 용어와 금지 동의어
- `docs/adr/`: 되돌리기 어렵거나 범위를 결정한 설계 판단
- `docs/game-design.md`: 현재 확정된 게임 규칙과 프로토타입 범위

파일이 없으면 별도 경고 없이 진행한다.

## 사용 규칙

- 이슈 제목, 코드 이름, 테스트 이름, 문서에서 `CONTEXT.md`의 표준 용어를 사용한다.
- `CONTEXT.md`는 용어집으로만 유지하고 구현 상세와 밸런스 수치는 넣지 않는다.
- 게임 규칙은 `docs/game-design.md`에 기록한다.
- 기존 ADR과 충돌하는 변경은 조용히 덮어쓰지 말고 어떤 결정을 다시 여는지 명시한다.
- 새 ADR은 변경 비용이 크고, 맥락 없이 보면 의외이며, 실제 대안 사이의 선택이었던 경우에만 추가한다.
