# 5×4 배치판과 6:5 전장을 사용한다

기존 4×6 배치판 결정을 다시 열고, 중앙 전장 배경의 6:5 비율과 실제 배치 가독성을 기준으로 4행×5열, 총 20슬롯을 사용한다.

5열×4행은 전열·중열·후열을 구분할 수 있는 깊이를 유지하면서도, 화면이 가로로 늘어져 보이지 않는다. 6:5 전장 배경의 중앙 배치판과도 자연스럽게 맞으며, 20슬롯은 복제·합성·배치 선택의 여지를 남기면서 빈 화면을 과도하게 채우지 않는다.

이 결정은 4×6을 명시한 `0002`의 배치판 크기 부분을 대체한다. 순환 트랙, 적 누적 상한, 한 바퀴에 불이익이 없는 규칙은 유지한다.
